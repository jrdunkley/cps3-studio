What this is

This page plays and builds music for Street Fighter III 3rd Strike using the game's own music driver, run from your ROM. Nothing is imitated: the sound you hear is the driver's output through a model of the arcade board's sample chip.

The three tabs

Game music plays the 49 pieces in the ROM. Each track can be muted or soloed. You can try the driver's pitch and speed controls, and the key lift, to hear what the game could do with them.

Sounds lists the instruments. Bank 0 holds the music instruments; a drum kit has a different sound on each key, a pitched instrument plays across the keyboard. Give instruments your own names; the names are kept in this browser and saved inside your projects.

My song turns a MIDI file into game music. Give each part an instrument, set its level and position, choose the loop, press Play. "Export for the game" saves a song file that a ROM build can install (docs/ROM_GUIDE.md).

Play starts at the bar on the position slider: |< goes back to the start, << 4 and 4 >> skip four bars, and dragging the slider while it plays jumps there. The driver is run silently up to that bar, so it sounds exactly as if it had played through. While it plays, volume, left/right, expression, transpose, mute and tempo change at once; other changes jump back to the same bar. The Level bars show what each part (or, under Game music, each track) is playing as you hear it. "Arrangements" opens the approved songs and the ones made by style\arrange3s.js.

What the game allows

  • 16 tracks, one note at a time on each. A part that plays chords needs one track per note of the chord: set its "Voices".
  • Tracks 13 to 16 are shared with the sound effects during a fight, so hits and voices cut into them. Put your most important parts first.
  • Only the sounds already in the game. They are 8-bit samples, so everything you write will sound like 3rd Strike.
  • 48 ticks to the beat. Notes are rounded to that grid when a MIDI file is imported.
  • Phrase markers tell the game where a musical phrase ends, so it can change music or lift the key on the line.

Keep it private

The data folder next to this page is made from your ROM. Do not share it. Song files you export contain only your own notes.
